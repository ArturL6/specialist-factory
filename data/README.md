# Demo datasets

All files in this directory are synthetic, generated by `python -m specialist_factory generate`. They contain no real customer records, human annotations, teacher credentials, teacher caches, or model checkpoints.

- `text_demo.jsonl`: synthetic e-commerce intent examples.
- `vision_demo.jsonl`: synthetic surface-condition samples, using the PNG files under `images/`.
- `multimodal_demo.jsonl`: synthetic image-text surface-condition samples, referencing the same image fixtures.
- `modernbert_jev_demo.jsonl`: synthetic e-commerce examples with `human_label` used as a **synthetic gold proxy**. It is not a human annotation dataset.

SQLite teacher caches and local training artifacts remain excluded by `.gitignore` because they can contain provider-derived metadata and are reproducible from the configs.
